# VisionArc

**VisionArc** - An AI-powered 3D web application for diabetic retinopathy screening with stunning live animations and medical-grade interpretability.

## Features
- 3D interactive UI with fluid animations
- Real-time fundus image screening
- Grad-CAM interpretability visualization
- Fully responsive design
- Lightning-fast inference
- Detailed severity classification

## Tech Stack
- **Backend**: Flask, PyTorch, Transfer Learning
- **Frontend**: React, Three.js, Framer Motion, Tailwind CSS
- **ML**: EfficientNet, Focal Loss, Grad-CAM
- **Deployment**: Docker, AWS/Heroku

## Quick Start
```bash
# Backend setup
cd backend
pip install -r requirements.txt
python app.py

# Frontend setup
cd frontend
npm install
npm start
```

## Project Structure

- `backend/` - Flask API + ML model
- `frontend/` - React 3D application
- `notebooks/` - ML development & analysis
- `data/` - Datasets
- `models/` - Trained weights
